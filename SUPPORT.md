# Support

- **Something is broken.** Open an
  [issue](https://github.com/Stiven-Gjekaj/RewardEnforcedLearning/issues/new/choose)
  and use the bug report template. Include the full command. Every run in this
  project is reproducible from its seed, so the command is usually all that is
  needed to see the same thing you saw.
- **An agent does not learn what you expected.** That is a bug report as well.
  Include the command, the digest that the run printed, and what you expected
  instead.
- **You want something added.** Open an issue with the feature request
  template.
- **You want to help.** Read [CONTRIBUTING.md](CONTRIBUTING.md) first.

This is a personal project, so a reply may take a while.
